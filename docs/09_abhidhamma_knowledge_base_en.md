# Canonical Knowledge Base: Abhidhamma Piṭaka

> **Normative sources**: Abhidhamma Piṭaka (Dhammasaṅgaṇī, Vibhaṅga, Dhātukathā, Puggalapaññatti, Kathāvatthu, Yamaka, Paṭṭhāna); Aṭṭhakathā (Atthasālinī, Sammohavinodanī, Pañcappakaraṇa-Aṭṭhakathā); Ṭīkā (Mūlaṭīkā, Anuṭīkā); Visuddhimagga + Paramatthamañjūsā; Abhidhammatthasaṅgaha + Abhidhammāvatāra.

## I. ONTOLOGY OF PARAMATTHA DHAMMAS

### 1.1 Foundational Definition

The Abhidhamma distinguishes two discursive levels:

| Level | Pāli | Criterion |
|---|---|---|
| **Conventional** | *sammuti-sacca* | Conceptual designations (paññatti): person, being, man |
| **Ultimate** | *paramattha-sacca* | Irreducible realities (*dhammas*) possessing intrinsic nature (*sabhāva*) |

The *paramattha dhammas* are four:

1. **Citta** (consciousness) — 89 types [121 with jhāna distinctions]
2. **Cetasika** (mental factors) — 52 types
3. **Rūpa** (materiality) — 28 types
4. **Nibbāna** (the unconditioned) — 1

> The first three are *saṅkhata* (conditioned, arisen from conditions). Only Nibbāna is *asaṅkhata* (unconditioned).

### 1.2 Fourfold Method of Analysis

Each *dhamma* is defined by four criteria (cf. Atthasālinī, Dhs-a):

| Criterion | Pāli | Analytical Function |
|---|---|---|
| **Characteristic** | *lakkhaṇa* | What the dhamma is in itself (*sabhāva-lakkhaṇa*) |
| **Function** | *rasa* (kicca-rasa) | What it does, its activity |
| **Manifestation** | *paccupaṭṭhāna* | How it manifests to the introspective mind |
| **Proximate cause** | *padaṭṭhāna* | The immediate condition for its arising |

## II. CITTA — CONSCIOUSNESS (89/121 TYPES)

### 2.1 Definition and Nature

**Atthasālinī** (Dhs-a 63): *Cinteti ti cittaṃ* — "That which cognizes is citta."

| Criterion | Value |
|---|---|
| **Lakkhaṇa** | Cognition of the object (*ārammaṇa-vijānana-lakkhaṇa*) |

| **Paccupaṭṭhāna** | Processual continuity (*sandahana-paccupaṭṭhāna*) |

## III. CETASIKA — MENTAL FACTORS (52 TYPES)

### 3.1 Definition

**Atthasālinī**: *Cetasikā ti cetasi uppajjanato, cetena sahajātato, cetaṃ ārammaṇaṃ sikkhantīti.*

| Criterion | Value |
|---|---|
| **Lakkhaṇa** | Arising with citta, depending on citta |
| **Rasa** | Co-arising (*ekuppāda*), co-cessation (*ekanirodha*), sharing the same object (*ekārammaṇa*) and the same base (*ekavatthuka*) |

## IV. RŪPA — MATERIALITY (28 TYPES)

### 4.1 Definition

**Atthasālinī**: *Ruppati ti rūpaṃ* — "That which is deformed / affected."

| Criterion | Value |
|---|---|
| **Lakkhaṇa** | Being deformed (*ruppana*) |
| **Rasa** | Dispersing (*vikiratī*) |
| **Paccupaṭṭhāna** | Being indeterminate (*avyākata*) |
| **Padaṭṭhāna** | Citta (for mind-born rūpas) |

### 4.2 Mahābhūta Rūpa (Primary Materialities) — 4

| # | Pāli | EN | PT | Lakkhaṇa | Rasa |
|---|---|---|---|---|---|
| 1 | **Paṭhavī** | Earth | Terra | Hardness (*kakkhāḷatta*) | Supporting |
| 2 | **Āpo** | Water | Água | Fluidity (*ābandhana*) | Cohesion |
| 3 | **Tejo** | Fire | Fogo | Heat (*uṇhatta*) | Maturation |
| 4 | **Vāyo** | Wind | Vento | Distension (*vitthambhana*) | Support/motion |

> The 4 mahābhūtas are **inseparable** — they never exist in isolation.

### 4.3 Upādā Rūpa (Derived Materialities) — 24

**Pasāda rūpa** (Sensitivities) — 5: cakkhu, sota, ghāna, jivhā, kāya

**Gocara rūpa** (Sense objects) — 4: vaṇṇa (color/visibility), sadda (sound), gandha (smell), rasa (taste)

> Tangible (*phoṭṭhabba*) is not counted separately because it consists of paṭhavī, tejo, and vāyo.

**Bhāva rūpa** (Sex) — 2: itthi-bhāva, purisa-bhāva

**Hadaya rūpa** (Heart base) — 1: material base of the mind

**Jīvita rūpa** (Material vitality) — 1

**Āhāra rūpa** (Nutriment) — 1: oja (nutritive essence)

**Pariccheda rūpa** (Limiting space) — 1: ākāsa-dhātu

**Viññatti rūpa** (Intimation) — 2: kāya-viññatti (bodily), vacī-viññatti (vocal)

**Vikāra rūpa** (Mutability) — 3: lahutā (lightness), mudutā (malleability), kammaññatā (wieldiness/adaptability)

**Lakkhaṇa rūpa** (Characteristics) — 4: upacaya (integration/production), santati (continuity), jaratā (aging/decay), aniccatā (impermanence)

## V. NIBBĀNA — THE UNCONDITIONED

### 5.1 Definition

**Visuddhimagga** (XVI.67–68): *Nibbāti ti nibbānaṃ* — "That where extinction (*vāna* = taṇhā) has ceased."

| Criterion | Value |
|---|---|
| **Lakkhaṇa** | Peace (*santi*), cessation of suffering |
| **Rasa** | Deathlessness (*accuti*), immortality |
| **Paccupaṭṭhāna** | Signless (*animitta*), undisturbed |
| **Padaṭṭhāna** | The path (*magga*) |

### 5.2 Classification

| Aspect | Pāli | Description |
|---|---|---|
| **Sa-upādisesa** | *Sa-upādisesa-nibbāna-dhātu* | Nibbāna with residue (khandhas still present — living Arahant) |
| **An-upādisesa** | *Anupādisesa-nibbāna-dhātu* | Nibbāna without residue (parinibbāna — final dissolution of the khandhas) |

> Nibbāna is **one** in essence; the distinction sa/an-upādisesa is conventional, relative to the state of the experiencer.

## VI. PAṬṬHĀNA — THE 24 CONDITIONS

### 6.1 Overview

The Paṭṭhāna is the seventh and crowning treatise of the Abhidhamma Piṭaka. It exhaustively expounds the conditional relations (*paccaya-naya*) among all *dhammas*.

| # | Pāli | EN | PT | Main Type |
|---|---|---|---|---|
| 1 | **Hetu-paccaya** | Root condition | Condição de raiz | The 6 roots (lobha, dosa, moha, alobha, adosa, amoha) condition co-nascent dhammas |
| 2 | **Ārammaṇa-paccaya** | Object condition | Condição de objecto | Every object conditions the consciousness and cetasikas that cognize it |
| 3 | **Adhipati-paccaya** | Predominance | Predominância | The dominant factor (chanda, vīriya, citta, vīmaṃsā) governs concomitants |
| 4 | **Anantara-paccaya** | Proximity | Proximidade | The immediately preceding citta conditions the subsequent one |
| 5 | **Samanantara-paccaya** | Contiguity | Contiguidade | Identical to the preceding but emphasizes immediacy |
| 6 | **Sahajāta-paccaya** | Co-nascence | Conascência | Dhammas arising at the same moment condition each other |
| 7 | **Aññamañña-paccaya** | Mutuality | Mutualidade | Subset of sahajāta — reciprocal conditioning |
| 8 | **Nissaya-paccaya** | Support | Suporte | That which serves as a base (*nissaya*) |
| 9 | **Upanissaya-paccaya** | Decisive support | Suporte decisivo | Strong condition, includes *ārammaṇa-*, *anantara-*, and *pakatūpanissaya* (natural) |
| 10 | **Purejāta-paccaya** | Pre-nascence | Pré-nascença | What arose earlier and still exists conditions what arises now |
| 11 | **Pacchājāta-paccaya** | Post-nascence | Pós-nascença | What arises later supports what already exists (as rain supports lilies) |
| 12 | **Āsevana-paccaya** | Repetition | Repetição | Each javana conditions the subsequent one through repetition |
| 13 | **Kamma-paccaya** | Kamma | Kamma | Cetanā (volition) conditions co-nascent and future dhammas |
| 14 | **Vipāka-paccaya** | Result | Resultado | Resultant dhammas mutually condition their co-nascents |
| 15 | **Āhāra-paccaya** | Nutriment | Nutrição | 4 āhāras: kabaḷīkāra (material), phassa, manosañcetanā, viññāṇa |
| 16 | **Indriya-paccaya** | Faculty | Faculdade | The 22 faculties dominate their co-nascents |
| 17 | **Jhāna-paccaya** | Jhāna | Jhāna | Jhāna factors (vitakka etc.) condition co-nascents |
| 18 | **Magga-paccaya** | Path | Caminho | Path factors condition co-nascents |
| 19 | **Sampayutta-paccaya** | Association | Associação | Associated nāma dhammas (ekuppāda, ekanirodha, ekārammaṇa, ekavatthuka) |
| 20 | **Vippayutta-paccaya** | Dissociation | Dissociação | Condition between nāma and rūpa (do not share all 4 factors) |
| 21 | **Atthi-paccaya** | Presence | Presença | What exists in the present moment conditions |
| 22 | **Natthi-paccaya** | Absence | Ausência | What has ceased conditions by its absence (= anantara applied inversely) |
| 23 | **Vigata-paccaya** | Disappearance | Desaparecimento | = natthi |
| 24 | **Avigata-paccaya** | Non-disappearance | Não-desaparecimento | = atthi |

### 6.2 Methods of Exposition

The Paṭṭhāna employs 6 methods (*chaka*):

1. **Tika-paṭṭhāna** — Conditions applied to the 22 triplets
2. **Duka-paṭṭhāna** — Conditions applied to the 100 couplets
3. **Duka-tika-paṭṭhāna** — Couplets × triplets
4. **Tika-duka-paṭṭhāna** — Triplets × couplets
5. **Tika-tika-paṭṭhāna** — Triplets × triplets
6. **Duka-duka-paṭṭhāna** — Couplets × couplets

Each method is applied in 4 modes: **anuloma** (direct), **paccanīya** (negative), **anuloma-paccanīya** (direct-negative), **paccanīya-anuloma** (negative-direct).

## VII. CITTA-VĪTHI — COGNITIVE PROCESSES

### 7.1 Definition

A *citta-vīthi* is the orderly sequence of cittas that constitutes a complete cognitive act. Each citta lasts exactly one *cittakkhaṇa* (mind-moment), consisting of:

| Phase | Pāli | Description |
|---|---|---|
| **Arising** | *uppāda* | The citta arises |
| **Presence** | *ṭhiti* | The citta endures (very brief) |
| **Dissolution** | *bhaṅga* | The citta dissolves |

### 7.2 Pañcadvāra-vīthi (Five-Door Cognitive Process)

Sequence for a sensory object of *atimahanta* (very great) intensity:

```
Bh → Bh → (object reaches the door) → Bc → Bu → Pv → Cv → Sp → St → Vt → J×7 → Td×2 → Bh...
```

| Position | Abbr. | Citta | Full Pāli | Function |
|---|---|---|---|---|
| −2, −1 | Bh | Past bhavaṅga | Atīta-bhavaṅga | Life-continuum |
| 0 | Bc | Vibrating bhavaṅga | Bhavaṅga-calana | Vibration caused by impression |
| 1 | Bu | Arrested bhavaṅga | Bhavaṅgupaccheda | Interruption of the stream |
| 2 | Pv | Five-door adverting | Pañcadvārāvajjana | Directs attention to the door |
| 3 | Cv | Sensory consciousness | Cakkhu/sota/etc.-viññāṇa | Cognizes the object |
| 4 | Sp | Receiving | Sampaṭicchana | Receives the object |
| 5 | St | Investigating | Santīraṇa | Investigates the object |
| 6 | Vt | Determining | Votthapana | Determines the response |
| 7–13 | J×7 | Javana (7 moments) | Javana | "Running" — kammically active phase |
| 14–15 | Td×2 | Registration | Tadārammaṇa | Registers the object |
| 16+ | Bh | Bhavaṅga | Bhavaṅga | Return to the life-continuum |

> **Note**: Tadārammaṇa only arises if the object is *atimahanta*. For *mahanta* (great) objects, it stops at javana. For *paritta* (slight) objects, only bhavaṅga vibrates.

### 7.3 Manodvāra-vīthi (Mind-Door Cognitive Process)

```
Bh → Bc → Bu → Ma → J×7 → Td×2 → Bh...
```

| Position | Citta | Function |
|---|---|---|
| Ma | Manodvārāvajjana | Mind-door adverting |
| J×7 | Javana | Kammically active phase |
| Td×2 | Tadārammaṇa | Registration |

### 7.4 Javana — The Decisive Phase

Javana is the crucial point of each vīthi:

| Type of Being | Number of Javanas | Significance |
|---|---|---|
| **Ordinary** | 7 | 7 kammically active impulses |
| **Dying** | 5 | Process at the moment of death |
| **Magga** | 1 | The magga-citta occurs only once |
| **Phala** | 2–3 | Phala-citta immediately follows magga |
| **Arahant (fruition)** | Many | Nirodha-samāpatti: sustained duration |

## VIII. KATHĀVATTHU — DIALECTIC AND REFUTATIONS

### 8.1 Logical Structure

The Kathāvatthu, attributed to Moggaliputta Tissa (c. 250 BCE), employs a formal dialectical method with 5 modes (*pañca-vāda*):

| Mode | Pāli | Structure |
|---|---|---|
| 1. Direct question | *anuloma-pucchā* | "Is X Y?" — "Yes" → derive contradiction |
| 2. Inverse question | *paṭikamma-pucchā* | Invert thesis and demonstrate absurdity |
| 3. Reciprocal application | *vatthu-gāma* | Apply same argument to parallel cases |
| 4. Scriptural citation | *niggaha* | Refute with Sutta/Vinaya passage |
| 5. Conclusion | *upanayana* | Derive logical conclusion |

### 8.2 Central Debates

#### 8.2.1 Puggalavāda (Kathāvatthu I.1)

**Vātsīputrīya thesis**: "There exists a person (*puggala*) that is known in a real and ultimate sense" (*saccikaṭṭha-paramatthena*).

**Theravāda refutation**:
1. If puggala is *paramattha*, it must be permanent and unchanging
2. But it experiences dukkha, changes, and is subject to rebirth
3. Contradiction: it cannot be simultaneously ultimate (*paramattha*) and impermanent
4. Conclusion: *puggala* is a conventional designation (*paññatti*), not an ultimate reality

#### 8.2.2 Temporality of Dhammas (Kathāvatthu I.6, XXI)

**Sarvāstivāda thesis**: "All exists" (*sabbam atthi*) — past, present, and future.

**Theravāda refutation**:
1. If past dhammas still exist, the temporal distinction collapses
2. Kamma already ripened (*vipāka-dinna*) cannot exist again
3. The 3 times are distinctions of existence (*bhāva*), not mere modes (*dravya*)
4. Only the present moment is *paramattha*; past and future are *paññatti*

#### 8.2.3 Other Key Debates

| Kathāvatthu | Refuted Thesis | Theravāda Position |
|---|---|---|
| I.2 | An Arahant can fall away | Impossible — kilesas are eradicated |
| I.7 | Citta is pure by nature | Citta is neutral, corrupted by defilements |
| II.1 | Sound is resultant | Sound is produced by mind (cittaja), not vipāka |
| XIII.1 | Transfer of merit | Puñña cannot be transferred; anumodanā generates new kusala |

### 8.3 Sammuti vs. Paramattha — Truth Criteria

| Criterion | Sammuti (Conventional) | Paramattha (Ultimate) |
|---|---|---|
| **Ontology** | Designations: "person", "being" | Irreducible dhammas: citta, cetasika, rūpa |
| **Language** | Common functional language | Precise technical terms |
| **Utility** | Daily communication | Meditative analysis and insight |
| **Truth** | True in conventional usage, false in essence | True in essence (*sabhāva*) |
| **Destruction** | If conceptually dismantled, it disappears | If conceptually dismantled, it remains |

> **Atthasālinī**: *Paramatthato hi rūpādīnaṃ dhammānaṃ atthitāya, paramatthato santipi dhammā paññāpiyantī ti.* — "Because dhammas such as rūpa etc. exist in ultimate reality, dhammas existing in ultimate reality are made known/designated."

## IX. TERMINOLOGICAL STANDARDS FOR PT/ES/EN TRANSLATION

### 9.1 General Principles

1. **Never translate dhamma as "phenomenon"** → use "reality/realities" or retain "dhamma"
2. **Retain technical terms in Pāli** when translation loses precision
3. **Kamma** (NEVER "karma") — mandatory Pāli form
4. **Consistency**: one Pāli term → one fixed translation

### 9.2 Normative PT Glossary

| Pāli | ✅ Correct (PT) | ❌ Incorrect | Justification |
|---|---|---|---|
| dhamma | realidade / dhamma | fenómeno | "Fenómeno" is Kantian; dhamma is sabhāva |
| kamma | kamma | karma | Pāli, not Sanskrit |
| citta | citta / consciência | mente, espírito | citta ≠ manas ≠ viññāṇa in technical context |
| cetasika | cetasika / factor mental | — | Retain Pāli when possible |
| rūpa | rūpa / materialidade | matéria, forma | "Matéria" is too physicalist |
| vedanā | sensação / vedanā | sentimento, emoção | vedanā ≠ emotion (which is a complex) |

| viññāṇa | consciência | alma, mente | Context determines: citta or viññāṇa |
| nibbāna | nibbāna | nirvana, extinção | "Extinction" is one-sided; retain Pāli |

### 9.4 Common Errors to Detect

1. **Sanskrit contamination**: karma, dharma, nirvana, sutra → kamma, dhamma, nibbāna, sutta
2. **Philosophical anachronism**: "substance", "essence", "pure consciousness" → neutral terms
3. **Western psychologism**: "subconscious", "unconscious", "ego" → bhavaṅga, asmimāna
4. **Generic translation**: "meditation" for samādhi, jhāna, vipassanā → distinguish
5. **False cognates**: saññā ≠ "consciousness", vedanā ≠ "emotion"
6. **Intra-corpus inconsistency**: same Pāli term translated differently
